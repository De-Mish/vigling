# com_modeli — компонент «Поиск моделей»

Компонент Joomla 6 для вывода отдельной витрины поиска моделей из таблиц:
- `#__vigling_user_searches`
- `#__vigling_search_slots`

Список строится по активным поискам мастеров и использует те же user custom fields, что и `com_poisk` / `com_aktsii`, для фильтров по городу, району и формату работы мастера.

Основной URL для тестирования после регистрации компонента:
- `index.php?option=com_modeli&view=list`

Плановый короткий маршрут:
- `modeli`
