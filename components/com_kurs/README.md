# com_kurs — компонент «Курсы»

Компонент Joomla 6 для вывода отдельной витрины курсов из таблиц:
- `#__vigling_user_courses`
- `#__vigling_course_slots`

Список строится по активным курсам мастеров и использует те же user custom fields, что и `com_poisk` / `com_aktsii`, для фильтров по городу, району и формату работы мастера.

Основной URL для тестирования после регистрации компонента:
- `index.php?option=com_kurs&view=list`

Плановый короткий маршрут:
- `kurs`
