## 2. Безопасность и логика (бэкенд)

Высокий приоритет:
- **DDL на живом сайте.** `ReviewHelper.php:15`, `OrderTable.php:42`, `FavoritesHelper.php:18` выполняют `CREATE TABLE` и `ALTER TABLE` при обычных запросах пользователей. Миграции нужно запускать один раз вручную.
- **Удаление записей.** `OrdersController.php:99` и `:1114` удаляют записи сырым `DELETE`, в обход `OrderTable::delete()`. Для акций не возвращается остаток, он может стать неверным.
- **Запись без каталога.** `Lkbooking.php:307-320`: если у мастера нет каталога услуг, цену и длительность можно подменить запросом.

Средний приоритет:
- `addservice.php:56`: любой вошедший пользователь может открыть форму редактирования чужой услуги.
- `article_create.php`: нет проверки категории и владельца, «редактирование» создаёт дубль.
- `Lkbooking.php:184`: `booking_kind=journal` можно отправить от любого пользователя, и клиент может занять слот мастера.
- `Lkbooking.php:506`: в ответ клиенту уходит текст исключения или SQL.
- `function.php` и `specialists-list.php`: отдельные скрипты вне Joomla без авторизации и CSRF.
- `Quickauth.php:216`: можно отправлять письма подтверждения на чужой адрес (есть пауза между отправками, но нужен лимит на IP).
- `AppointmentsHelper.php:167`: до 500 строк за выборку, при активном мастере будет тяжело.

Низкий приоритет: жёстко прописанные ID групп 3 и 8 (`OrdersController.php:1799`), открытый календарь по ID мастера, `getInbox` через GET и другое.

Положительное: проверка токена и владельца в большинстве действий `com_orders`, блокировки и транзакции в бронировании, проверка внутренних адресов при редиректах.

## 3. Фронтенд, PWA, SEO

Высокий приоритет:
- Bootstrap 4.5.2 (JS и CSS) загружается с `stackpath.bootstrapcdn.com`. Эта CDN закрыта. Нужно хранить на своём сервере.
- `profile/default.php:1937`: при включении пуш-уведомлений удаляются все service worker, а не только лишние.

Средний приоритет:
- `firebase-messaging-sw.js`: скрипты кэшируются «сначала кэш», после выкладки у пользователей может остаться старый JS. Страницы тоже могут показываться устаревшими.
- `pwa_maker_service_worker.js`: старый service worker кэширует почти все GET-запросы.
- Модальное окно записи: `aria-labelledby="zapisModalLabel"` ссылается на несуществующий элемент.
- Кнопки «Далее» и отправки в записи сделаны через `div`, а не `button`: с клавиатуры не нажать.
- Время записи при отсутствии `data-time-utc` считается по часовому поясу браузера (`default_public.php:3081`, `profile/default.php:1691`).
- `jquery-migrate-1.4.1` подключён к jQuery 3.4.1.
- `jquery.datetimepicker` загружается дважды на каталоге.
- Выбор слота по `pointerdown` и `click` одновременно.
- Журнал: ошибка загрузки дней молча останавливает подгрузку.
- `sitemap.xml` устарел (2022), включает `/login` и страницы кабинета. В `robots.txt` нет строки `Sitemap:`.

Низкий приоритет: нет SRI у сторонних скриптов, `manifest.json` фиксирует портретную ориентацию, в окне быстрой авторизации нет закрытия по Esc и ловушки фокуса.

## 4. Дизайн и CSS

Высокий приоритет:
- `<jdoc:include type="styles" />` в `index.php:186` стоит после `redesign.css`, поэтому стили компонентов могут перебить редизайн.
- Мобильная версия начинается с разных ширин: `mobile-redesign.css` работает до 768px, а редизайн до 1020px. На планшетах 769-1020px получается смесь старого и нового вида. Ещё есть 767, 820 и 821.
- Кнопка «Записаться» описана в трёх слоях CSS с разной высотой (30, 40 и больше). Побеждает 30px, что меньше удобных для касания 44px.
- Нижняя панель «Сохранить / Отмена» в профиле перекрыта нижним меню на ширинах 769-1020px.

Средний приоритет: серый `#8a8f98` на белом и на `#fff7da` с низким контрастом; чипы фильтров 36px; крестик на карте 28px; `design-tokens.css` дублирует токены редизайна; `100vh` без `100dvh` в `style-ext.css`; очень большие значения `z-index`; в `style.css` остаются ссылки на `GothamPro*` (они теперь указывают на Montserrat, но лучше заменить на общую переменную шрифта).

Вес CSS около 545 КБ, около 160 КБ в репозитории лишние (`_style*.css`, дубли FontAwesome).
