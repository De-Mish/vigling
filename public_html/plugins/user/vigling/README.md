# User — Vigling

Плагин группы **User** для Joomla 6. Расшифровка и отображение закодированных Custom Fields пользователя, перенесённых из JSN (joomla_jsn_users).

## Назначение

После миграции данных JSN в Custom Fields (com_users.user) поля **prices**, **vyberite_spetsialnos**, **work_day**, **stock_prices** хранят JSON/массивы. В форме редактирования пользователя в админке они отображались как сырая строка или вызывали ошибки. Плагин:

- добавляет в форму пользователя вкладку **«JSN (расшифровка)»**;
- на вкладке выводит человекочитаемую расшифровку этих полей;
- нормализует значения-массивы в полях вкладки «Поля» (преобразует в строку), чтобы не было ошибок отображения;
- при наличии значений в «Поля» подменяет сырой текст на расшифрованный (во вкладке «Поля»).

## Зависимости

- **Категории** — из `#__categories` (extension=com_content, услуги по parent_id/path). **Услуги** — из `#__vigling_services` (таблица создаётся и заполняется скриптом `migration_scripts/19_vigling_services_table.php` из бывшего lookups.json). Файл lookups.json не используется.

## Структура

| Путь | Назначение |
|------|------------|
| `src/Extension/Vigling.php` | Подписка на `onContentPrepareForm`, добавление вкладки и поля, нормализация значений в форме. |
| `src/Field/JsndecodeField.php` | Кастомное поле типа `jsndecode`: загружает значения из `#__fields_values` для текущего пользователя и выводит расшифровку. |
| `src/Helper/JsnDecodeHelper.php` | Расшифровка значений (prices, work_day, vyberite_spetsialnos), структурированный вывод цен по категориям. |
| `forms/user.xml` | Описание вкладки `jsn_decode` и поля `jsndecode`. |
| `services/provider.php` | Регистрация плагина в DI. |
| `language/*/plg_user_vigling.ini` | Строки вкладки и сообщений. |

## Обрабатываемые поля

| Имя поля | Формат в БД | Отображение |
|----------|-------------|-------------|
| prices, stock_prices | `{catId:[[цена, мин, id_услуги],...],...}` | Карточки по категориям, нумерованный список: услуга — цена руб, мин. |
| work_day | `[1,2,3,4,5]` | Пн, Вт, Ср, Чт, Пт. |
| vyberite_spetsialnos | `{"0":"18","6":"16"}` | Названия категорий из lookups или «#id». |

## Установка

Установка через **Расширения → Установить** (ZIP) или копирование в `plugins/user/vigling/`. После установки включить плагин **User — Vigling** в **Расширения → Плагины**. Namespace `Joomla\Plugin\User\Vigling` регистрируется манифестом плагина (Joomla 6).

## Текущее состояние

- Вкладка «JSN (расшифровка)» отображается в форме редактирования пользователя (Админка → Пользователи → пользователь → редактировать).
- Цены выводятся структурированно (Bootstrap card/list-group), без проблем с цветом текста в светлой/тёмной теме.
- Рабочие дни и специальности расшифровываются и показываются текстом.
- Плагин группы User гарантированно вызывается для формы com_users.user; отдельный плагин System для этой задачи не используется.
